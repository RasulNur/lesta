# Lesta Project

## Функционал

На главной страние выведены все корабли. На главной странице и странице поиска реализованы фильтрация по типу, уровню и нации, пагинация. Сайт адаптирован под мобильные утсройства.

## Технологии

-   Next.js (v. 15.2.4)
-   TypeScript

## Установка и запуск

npm install

npm run dev

http://localhost:8080/
