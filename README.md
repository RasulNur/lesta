# Lesta Project

## Функционал

На главной страние выведены все корабли. На главной странице и странице поиска реализованы:

-   фильтрация по типу, уровню и нации;
-   пагинация.

Сайт адаптирован под мобильные утсройства.

## Технологии

-   Next.js (v. 15.2.4)
-   TypeScript
-   Tailwind

## Установка и запуск

### Устновка пакетов

npm install

### Запуск сайта

npm run dev

### Сайт запускается на:

http://localhost:8080/
